📌 How to add next week's reports

  1. Drop the new report .html file into this same folder, next to index.html.
  2. Open index.html in a text editor and find the const reports = [ ... ] list near the bottom of the file.
  3. Copy one existing entry, paste it as a new line, and edit type ('mom' or 'yoy'), title, date, workingDays, and file (the exact filename you just added).
  4. Save — no other changes needed. The new report will automatically appear in the right tab and in "All Reports", sorted by date.
